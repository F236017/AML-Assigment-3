🎓Analysis — Task 6 Answers

6.1 — Always-"N" Accuracy

An always-N model scores 82.76%. Our model scores 97.80%. Despite both seeming "high", the always-N model is clinically useless — it never detects a single arrhythmia. Balanced accuracy (85.34% vs 82.76%) reveals the real gap.

6.2 — Hardest Class

S has the lowest per-class accuracy (68.53%), mostly confused with N. Supraventricular beats are biologically similar to normal beats — only subtle P-wave timing differences separate them, which a small network struggles to distinguish.

6.3 — Overfitting?

A small but stable gap exists between train (98.34%) and val (97.94%) accuracy. This is mild overfitting — not severe. Loss plateaus at epoch 21, confirming an appropriate model size.

6.4 — He Init & Why Not Zero

Zero init → all neurons identical → gradient symmetry never breaks → training fails. He init uses std = √(2/n) because ReLU zeroes half inputs on average (halving variance); the factor of 2 restores it, keeping activations well-scaled.

6.5 — Momentum & Weight Decay

Momentum: opposing gradients partially cancel in the velocity → update slows in noisy directions, stays fast in consistent directions. Weight decay: a weight with zero gradient still decays P ← P(1−αλ), penalising large unused weights.

6.6 — Helping Class F (641 samples)

Class-weighted loss: weight each sample by w_j = N/(C·n_j). An F-class miss contributes ~113× more than an N-class miss, forcing the network to focus on rare classes during training.
